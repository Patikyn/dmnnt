# DMNNT — головна сторінка

Лендинг агенції спортивного спонсорства та PR DMNNT. Написаний на чистому HTML, CSS і JS без збірки. Розміри задані в `rem`: на ПК 1rem = 16px при ширині 1920, на мобілці 1rem = 16px при 375. Тому макет масштабується на будь-якому екрані.

Макет у Figma: файл `ffjdsB0KRCVdgZeKYuZ6c1`, сторінка «Design PC Updated (перевірені)»:
- ПК — фрейм `01` (`521:2575`);
- мобілка — фрейм `Mobile/Homepage ALT` (`521:2912`).

## Файли

| Файл | Що в ньому |
|---|---|
| `index.html` | розмітка всіх секцій |
| `styles.css` | стилі ПК, у кінці мобільний шар `@media (max-width: 767px)`; у коментарях є node-id з Figma |
| `main.js` | анімації: поява секцій при скролі, плашки від воріт до центру, хрестик за мишею, паралакс, бургер-меню, зміна предметів у футері |
| `assets/` | шрифти (Neutral Face, Inter), фото WebP, відео першого екрана (AV1 і H.264) |
| `_parked/news-section.html` | секція Highlights, тимчасово знята зі сторінки, її CSS лишився в `styles.css` |

## Як запустити локально

```bash
python3 -m http.server 8126
```

Потім відкрити http://localhost:8126.
